# A step with a screen

Read only when the step has a screen. [Impeccable](../../../../docs/reference/impeccable.md) owns
which of its commands, hooks and configuration Conexus allows.

- Refuse the step's study report when the step has a screen and the report has no captures
  folder: no "What a person saw" without shots is no study of a screen. Say so as a finding.
- Compare each changed screen with the old shots the card carries, state by state.
- Open the screen the founder approved (the chosen design or the proposal's prototype) beside the
  built one and compare them element by element: each element it draws (logo, name, pill,
  coloured dot, badge) is in the build, or the card records why not. A criterion's text is not the
  screen. Failure: the Fontes block shipped as one grey line, poorer than the approved prototype,
  and review and QA passed it against the criterion.
- Read every matrix cell that says "sem detalhe" or "não abre" against the founder's page
  ([scope screens](../../conexus-scope/references/screens.md) 5): one without his word is a finding.
- Use `critique` and `audit` as one more lens. A finding of it never blocks alone;
  [delivery L12](../../../../docs/guides/delivery.md) judges it.
