# 0032. Each company is told what leaves Brazil

## Context

Data of the apps and the Hub stay in São Paulo; conversations go to the model vendor and code under construction to E2B. Excerpts read from the integrations a Projeto released go to the model vendor. Rows the Assistant reads from a company's connections go to its conversation's machine on E2B, outside Brazil, for as long as the conversation exists.

## Decision

Before it enters, each company is told in writing what leaves Brazil. Basis: The founder's answer.

## Criterion

None written before. Brought from earlier work.

## Result

Where each vendor stores data was not read.

## Consequences

A written notice per company.

## Reopens when

A vendor changes where it processes data, or a company refuses.

Brought. Founder, 2026-10-13: "8. A".
