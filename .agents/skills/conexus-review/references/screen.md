# A step with a screen

Read only when the step has a screen. [Impeccable](../../../../docs/reference/impeccable.md) owns
which of its commands, hooks and configuration Conexus allows.

- Refuse the step's study report when the step has a screen and the report has no captures
  folder: no "What a person saw" without shots is no study of a screen. Say so as a finding.
- Compare each changed screen with the old shots the card carries, state by state.
- Use `critique` and `audit` as one more lens. A finding of it never blocks alone;
  [delivery L12](../../../../docs/guides/delivery.md) judges it.
