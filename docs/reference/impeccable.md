# Impeccable in Conexus

Impeccable is a front-end skill installed on the machine, not in this repository. Conexus uses its
commands for structure and review and, in the visual phase of the redesign, to draw directions; the
repository owns the visual identity ([design](../guides/design.md)) and the skills of
[`docs/index.md`](../index.md) cite this file for what is allowed. Founder, 2026-10-19: "Aprovado
tudo" on the structure study, call 6 A; on opening the visual phase, 2026-11-26: "3. Sim".

## What the repository holds

- `DESIGN.md` at the root holds the values and the pieces, in the DESIGN.md format; the design
  guide holds the rules. Impeccable reads the root file; each fact has one owner.
- `PRODUCT.md` at the root is short and cites the document that owns each section.
- `.impeccable/config.json`: `buildPath` is `code`; the age check is off; `kicker-above-heading` is
  ignored for now: the `eyebrow` token of `DESIGN.md` exists, and the guide (V61) already forbids the
  kicker the detector looks for, so turning it on is a future issue. Its craft floor also calls a grey screen with
  one accent the dull default: direction B in graphite ([design](../guides/design.md)), which the
  founder approved ("Fecha", 2026-11-26), decides, so that advice yields.
- The hooks are in `.claude/settings.json` of this repository only (`SessionStart`, `PostToolUse` on
  `Edit|Write`, `Stop`), never in a person's global settings. Each one does nothing when
  Impeccable is not installed.

## Commands

Allowed:

| Skill | Commands |
| --- | --- |
| `conexus-study` | `critique` on today's screen and the captures; the questions of `shape` phase 1 |
| `conexus-scope` | the `shape` summary (phase 3) as the card's screens section; `onboard` when the step has a first time |
| `conexus-build` | `layout`, `adapt`, `harden`, `clarify` (design V39) on a screen unit; at the end `impeccable detect` on the changed files |
| `conexus-review` | `critique` and `audit`, as one more lens |

In the visual phase:

| Work | Commands |
| --- | --- |
| Drawing the redesign's visual directions, in study prototypes outside the repository | `new-work`, `live`, `generate` |
| The unit whose card names it | `document`, which writes `DESIGN.md` from the approved direction, B in graphite |

Forbidden: `extract` (it writes `DESIGN.md`); `bolder`, `colorize`, `overdrive` and `delight`; in a
build unit, `new-work`, `live`, `generate` and any other path that redesigns and replaces the
approved direction.

  like any other.
