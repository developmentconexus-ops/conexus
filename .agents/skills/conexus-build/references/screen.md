# A screen unit

Read only when the unit changes a screen. [Impeccable](../../../../docs/reference/impeccable.md)
owns which of its commands, hooks and configuration Conexus allows.

- Use `layout`, `adapt` and `harden` on the screen unit, and `clarify` for its texts
  ([design V39](../../../../docs/guides/design.md)).
- At the end, run `impeccable detect` on the changed files.
- A finding of it never blocks alone; [delivery L12](../../../../docs/guides/delivery.md) judges it.
- Build to the card's box layouts and the old shots it carries; the state matrix's "primeira vez"
  and "sem permissão" columns are states to build and look at.
