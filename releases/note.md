# v0.24.111

Nada muda para quem usa o Conexus. Esta versão arruma por dentro a forma como o Builder, o
Assistente, o Construtor de apps e os agentes publicados montam cada conversa: o que antes estava
copiado em três lugares passa a existir num só. As telas, os nomes, as respostas e as conversas de
hoje continuam iguais.

É o primeiro passo da etapa "Uma ficha por agente". Junto com ele entra um teste que guarda o pedido
de cada agente ao modelo e avisa se uma mudança alterar um só caractere dele, para que os próximos
passos também não mudem nada para quem usa.
