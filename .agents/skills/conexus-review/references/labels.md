# A finding on the border

Read when a finding could take two labels of [delivery L12](../../../../docs/guides/delivery.md).

1. Does someone lose something in this step's use script or operation? Bloqueia.
2. Is it the first file of its kind, wrong, and copied next? Bloqueia.
3. Does the loss appear only when the code later changes? Fechamento, unless two owners can
   diverge.
