# Perguntas

- `perguntas`: questions on the seller's listings with the answer when there is one, up to 50 per page, filtered by `status`. Unanswered questions stay visible for 7 months. The asker is not in the answer. The search reads at most 1000 questions (Mercado Livre's offset cap): with more, narrow it with `status`; there is no way past 1000.
- `tempoDeResposta`: the seller's average answer time, in minutes.
