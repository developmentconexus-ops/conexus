# v0.24.116

Nada muda para quem usa o Conexus. Esta versão arruma por dentro a troca de modelo: as três rotas
que trocam o modelo de uma conversa (a do Builder, a do Assistente e a do Construtor de apps)
passam a usar uma parte comum, em vez de cada uma repetir o mesmo trecho. As telas, os nomes, as
respostas e as conversas de hoje continuam iguais.

É o sexto passo da etapa "Uma ficha por agente". O teste que guarda o pedido de cada agente ao
modelo continua passando sem ser regravado.
