# Aprovações e usos das etapas

O registro de cada cartão, num arquivo com o nome do arquivo do cartão: as palavras do fundador ao aprovar o cartão e as emendas, com a data e o commit, e ao usar a etapa, com a data e o endereço (delivery L6, L17). As mudanças do método ficam em [metodo.md](metodo.md); as decisões fora de um cartão, em [fora-de-uma-etapa.md](fora-de-uma-etapa.md). A linha de cada etapa está no [roteiro](../roadmap.md).
